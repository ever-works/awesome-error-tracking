- [Dynatrace](https://www.dynatrace.com/) - Dynatrace is an AI-powered observability and APM platform with automated error detection. ([Read more](/details/dynatrace.md)) `Paid` `Enterprise` `AI-Powered` `APM` `Full-Stack`
- [New Relic](https://newrelic.com/) - New Relic is an observability platform that includes APM and error tracking for cloud-native applications. ## Open-Source & Self-Hosted

- [Errbit](https://github.com/errbit/errbit) - Errbit is an open-source, self-hosted error catcher compatible with the Airbrake API. It is designed for teams that want to host their own exception tracking. It is free to use under the MIT license. ([Read more](/details/errbit.md)) `Open Source` `Self-Hosted` `Airbrake-Compatible` `Error Tracking`
- [Exceptionless](https://exceptionless.com/) - Exceptionless is an open-source error tracking and reporting service for .NET and other platforms. It can be self-hosted or used as a cloud service and includes feature usage tracking. It is free to self-host. ([Read more](/details/exceptionless.md)) `Open Source` `Self-Hosted` `.NET` `Error Tracking`
- [GlitchTip](https://glitchtip.com/) - GlitchTip is an open-source, self-hosted error tracking tool compatible with Sentry SDKs. It focuses on simplicity and privacy for teams that want to host their own data. It is free to use under an open-source license. ([Read more](/details/glitchtip.md)) `Open Source` `Self-Hosted` `Sentry-Compatible` `Free`
- [PostHog Error Tracking](https://posthog.com/) - PostHog is an open-source product analytics platform that includes error tracking and session replay. It can be self-hosted or used as a managed cloud service. It offers a generous free tier and paid plans.
